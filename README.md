# Бот казахских новостей для Instagram

Бот сам находит свежие новости Казахстана в открытых СМИ и выбирает самую важную. Затем он пишет сценарий на казахском, сверяет факты со статьёй, озвучивает текст нейроголосом, собирает анимированный Reels и публикует его. Так **3 раза в день**: бот просыпается каждые 2 часа с 8:00 до 22:00 по Астане и выкладывает 3 ролика с перерывом от 3 часов. Если серверы ИИ заняты, он просто попробует в следующий раз. Всё бесплатно: работает на GitHub, ваш компьютер не нужен.

```
RSS казахстанских СМИ ─► ИИ выбирает новость ─► ИИ пишет сценарий на казахском
   ─► ИИ-редактор сверяет факты со статьёй ─► озвучка (голос Даулет/Айгуль)
   ─► видео 1080×1920 в стиле примера ─► Instagram Reels + подпись + источник
```

**Что стоит 0 ₸:** GitHub Actions (сервер и расписание), Gemini API (бесплатный уровень), озвучка Microsoft через edge-tts, GitHub Pages (ссылка на видео для Instagram), Instagram API.

## Настройка (один раз, ~40 минут)

### 1. Instagram-аккаунт
1. В приложении: **Настройки → Тип аккаунта и инструменты → Переключиться на профессиональный → Бизнес**.
2. Старые публикации: **⋯ → Архивировать** (они скроются, но не удалятся; вернуть можно в любой момент).
3. Смените имя, ник и описание под новости. Затем впишите ник в `config.yaml` → `handle`.

### 2. GitHub (сервер бота)
1. Зарегистрируйтесь на github.com и создайте **публичный** репозиторий (например, `kz-news-bot`). Публичный нужен, чтобы бесплатно работали Pages и неограниченные минуты. Секреты при этом никто не видит.
2. Загрузите в него все файлы этой папки: **Add file → Upload files**, перетащите всё, кроме `node_modules`.
3. **Settings → Pages → Source: GitHub Actions**.
4. **Settings → Actions → General → Workflow permissions: Read and write**.

### 3. Бесплатный ключ ИИ (Gemini)
1. Откройте aistudio.google.com → **Get API key → Create API key**.
2. В GitHub: **Settings → Secrets and variables → Actions → New repository secret**. Имя `GEMINI_API_KEY`, значение — ключ.

### 4. Токен Instagram
1. Зайдите на developers.facebook.com, создайте приложение (тип **Business**) и добавьте продукт **Instagram**.
2. Откройте **API setup with Instagram login → Generate access tokens → Add account** и войдите в ваш Instagram. Если попросят, добавьте аккаунт в **App roles → Roles → Instagram Testers** и примите приглашение в Instagram: **Настройки → Приложения и сайты**.
3. Скопируйте токен и сохраните его как секрет `IG_ACCESS_TOKEN`.
   Публиковать в собственный аккаунт можно без проверки приложения со стороны Meta.

### 5. Автопродление токена (чтобы не трогать бота через 60 дней)
1. GitHub: **Settings (профиля) → Developer settings → Fine-grained tokens → Generate**. Доступ дайте только к этому репозиторию, в разделе Permissions выберите **Secrets: Read and write**.
2. Сохраните его как секрет `GH_PAT`. Тогда бот продлевает токен Instagram 1-го и 15-го числа сам.

### 6. Пробный запуск
1. **Actions → Новостной Reels → Run workflow** (галочка «Только собрать видео» включена) → Run.
2. Через ~8 минут откройте запуск, внизу будет **Artifacts → reel**. Скачайте и посмотрите ролик и подпись (`meta.json`).
3. Если всё нравится, ничего больше делать не нужно: по расписанию бот публикует сам. Чтобы выложить прямо сейчас, запустите вручную со снятой галочкой.

## Управление
| Что нужно | Как |
|---|---|
| Поставить на паузу | **Settings → Secrets and variables → Actions → Variables** → `BOT_PAUSED` = `true` |
| Сколько постов в день и перерыв | `config.yaml` → `posts_per_day`, `min_gap_hours` |
| Часы работы | `.github/workflows/post.yml`, строка `cron` (время в UTC = Астана − 5 ч) |
| Женский голос | `config.yaml` → `voice: kk-KZ-AigulNeural` |
| Свои источники новостей | `config.yaml` → `feeds` |
| Стоп-слова | `config.yaml` → `skip_keywords` |
| Стоковые фото в роликах | бесплатный ключ pexels.com/api → секрет `PEXELS_API_KEY` |
| Текст получше (платно, ~$1–3/мес) | ключ console.anthropic.com → секрет `ANTHROPIC_API_KEY` (тогда пишет Claude вместо Gemini) |

Если запуск упадёт, GitHub пришлёт письмо на почту. Следующий запуск по расписанию попробует снова.

## Защита от ошибок
- Новость берётся только из СМИ, и в каждом посте указан источник («Дереккөз»).
- Второй проход ИИ сверяет каждую цифру и имя со статьёй, правит казахскую грамматику и может забраковать новость.
- Бот пропускает криминал с жертвами, трагедии, слухи, рекламу и гороскопы, а также не повторяет уже опубликованные темы (`state/posted.json`).
- Фото из новостей не используются (это чужие авторские права). Ролики либо чисто графические, либо со стоковыми фото Pexels.

## Локальный запуск (необязательно)
```bash
pip install -r requirements.txt && npm ci --prefix video
GEMINI_API_KEY=... python -m bot.main build    # результат в out/reel.mp4
python -m bot.main demo                        # демо-ролик без ИИ
```
